# Catalog rules

- This package contains pure TypeScript catalog, import-normalization, status and search logic.
- No React, browser, WebSocket, database, file-system or engine dependencies.
- Card text is display/catalog information only and must never become parser input.
- Import status must not grant Engine, AI, deck-validation or match-start playability.
- Keep API payload helpers free of Match, Token, FullState and Hidden-Info data.
