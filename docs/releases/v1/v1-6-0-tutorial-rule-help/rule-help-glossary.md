# V1.6.0 Regelhilfe-Glossar

Stand: 2026-05-08  
Status: aktiv für V1.6.0 Tutorial und Regelhilfe

## Glossar

| Begriff | Kurzdefinition |
| --- | --- |
| Korp | Verteidigende Seite, die Server aufbaut und Agenden scored. |
| Runner | Angreifende Seite, die Runs startet und Agenden stealt. |
| Klick | Aktionspunkt pro Zug. |
| Credit | Zahlmittel für Aktionen und Fähigkeiten. |
| HQ | Hand der Korp. |
| F&E (R&D) | Nachziehstapel der Korp. |
| Archive | Ablagebereich der Korp. |
| Außenserver | Von der Korp erstellter Remote-Server. |
| Run | Angriff des Runners auf einen Server. |
| Begegnung | Run-Phase gegen ICE inklusive Rezzen/Subroutinen. |
| Zugriff | Access auf Karten nach erfolgreichem Run. |
| Agenda | Siegpunktkarte für Korp (Score) oder Runner (Steal). |
| Tag | Runner-Marker, der bestimmte Korp-Maßnahmen erlaubt. |
| Schaden | Kartenschaden gegen den Runner; bei leerer Hand droht Flatline. |
| LegalAction | Von der Rules Engine freigegebene, regelkonforme Aktion. |

## Scope-Hinweis

Die Regelhilfe erklärt nur NETGRID-Scope und nur erlaubte Projektionen aus PlayerView, LegalActions und side-gefilterten Events. Sie ersetzt keine Rules-Engine-Entscheidung.
