# V1.0.9 Private Internet Hardening

Status: migrated-release-family
Moved: 2026-05-18

## Zweck

Diese Familie bündelt den V1.0.9-Rand-Härtungsrelease für privaten Internetbetrieb. Der Scope umfasst Transport, Deployment-Profile, Origins, CORS, WebSocket-Gates, Rate Limits, Secrets, Redaction, Health/Ops und internetnahe Smokes.

Der Release macht NETGRID nicht zu einer öffentlichen Plattform: keine Accounts, öffentlichen Lobbys, Matchmaking-, Ranking-, Turnier-, Chat-, Moderations-, Postgres-, Karten-, Mechanik-, Replay-/StateHash- oder Engine-Autoritätsänderungen.
