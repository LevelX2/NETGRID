# V2.6 Moderation

Diese Gruppe bündelt Moderation, Evidence, RBAC, Redaction, Evidence-Export und den Moderator-Runbook-Entwurf.

## Artefakte

- `evidence-rbac-contract.md`: Rollen, Datenklassen, Zugriffsmatrix, Default-Deny und Break-Glass.
- `rbac-redaction-test-matrix.md`: Testmatrix für RBAC und Redaction-Gates.
- `evidence-export-contract.md`: Evidence-Exportgrenzen und Exportverbote.
- `moderator-runbook-draft.md`: Entwurf für Reporteingang, Triage, Evidence-Sichtung, Entscheidung, Audit und Appeals.
