# V2.2 Chat Safety

Diese Gruppe sammelt die Chat-Verträge für Datenmodell, Retention, Redaction, Boundary-Tests, Report, Block und sichere UI-Zustände.

## Artefakte

- `chat-data-contract.md`: Chatdatenmodell, Retention und Export-/Löschgrenzen.
- `chat-redaction-boundary-test-plan.md`: Boundary-Testplan für Reconnect, WebSocket, Server-Payloads, Replay, Logs und Evidence.
- `chat-report-block-ui-contract.md`: Reportziele, Block-Semantik, sichere UI-Zustände und Moderationshandoff.
