# AI-Release-Dokumentation

`docs/releases/ai/` bündelt abgeschlossene KI-bezogene Release- und Approval-Spuren, die nicht sauber in eine einzelne V1-Releasefamilie passen oder mehrere Releases überspannen.

## Bereiche

- `deck-doctrine/`: Requirements, Plan, Testmatrix, Implementation Review und Benchmark-Reports zur Deck Doctrine.
- `deck-legal-approval/`: Batch-, Open64-, V1.9.x- und Einzelkarten-Approval-Nachweise für KI-Unterstützung bereits spielbarer Karten.

## Regel

Diese Dokumente sind Gate- und Evidence-Artefakte. Neue Kartenfreigaben, Runtime-Promotionen oder AI-Hints entstehen nur durch eigene Implementierungspakete, nicht durch diesen Dokumentationsmove.
