Verbleibende unsichere Karten: keine ungepaarte Karte nach Titel+Side. Einzelne Zielprimitive bleiben bewusst konservativ als pending/legacy, wenn die genaue spätere DSL-Grenze noch Trigger, Target Binding, Hidden Info, Counter, Region oder Run/Access Replacement benötigt.
