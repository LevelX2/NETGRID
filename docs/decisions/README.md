# Entscheidungen

`docs/decisions/` enthält dauerhafte Projekt-, Produkt-, Quellen- und Dokumentationsentscheidungen, die nicht klar zu einer einzelnen Releasefamilie oder Architekturunterlage gehören.

## Enthaltene Artefakte

- `docs-structure-target-decision-2026-05-18.md`: Zielstruktur für `docs/` und Migrationsregeln.
- `onr-v1-card-attribute-conflict-decisions-2026-05-13.md`: entschiedene lokale O:NR-v1-Attributkonflikte.

## Regel

Entscheidungen werden nicht gelöscht, solange sie Pfade, Quellenlage, Karteninterpretation, Git-/Asset-Grenzen oder Projektstruktur begründen.
