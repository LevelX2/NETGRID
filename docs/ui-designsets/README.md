# UI-Designsets

Diese Bilder sind explorative UI-Mockups für den privaten Netrunner-Client. Sie sind keine verbindliche Implementierungsvorgabe, sondern visuelle Richtungen für spätere UI-Entscheidungen.

Eine gesonderte Bewertung der Umsetzungsrealistik liegt hier: [Realismusprüfung](REALISM_REVIEW.md).

## Gemeinsame Anforderungen

- Runner- und Corp-Oberflächen sind getrennte Side-Views.
- UI-Eingaben sollen aus `LegalActions` abgeleitet sein.
- `StateVersion`, Reconnect, Undo und Event-/Replay-Hinweise sollen sichtbar gedacht werden.
- Verdeckte gegnerische Kartendaten dürfen nicht sichtbar sein.
- Keine offiziellen Artworks, Logos, Card Frames, Card Backs oder externen Kartendatenbank-Stile.
- Kein öffentlicher Plattform-Scope: kein Matchmaking, keine Rankings, kein Accountsystem, kein Deckbuilder, keine Turnierfunktionen.
