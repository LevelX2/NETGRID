# UI-Designsets

Stand: 2026-08-12

Diese Bilder sind kuratierte UI-Referenzen für den privaten NETGRID-Client. Sie sind keine verbindliche Implementierungsvorgabe.

Eine gesonderte Bewertung der Umsetzungsrealistik liegt in [REALISM_REVIEW.md](REALISM_REVIEW.md).

## Aktiver Stand

- Primärreferenz: Design C unter `active/design-c/`.
- Ergänzung für Run-/Encounter-Fokus: Design D unter `active/design-d-run-focus/`.
- Vorläufige NETGRID-Markenrichtung: `branding/`.

Historische Explorationen, verworfene Designs und ersetzte Drafts werden nicht mehr im Arbeitsbaum konserviert. Sie bleiben über die Git-Historie nachvollziehbar.

## Gemeinsame Anforderungen

- Runner- und Corp-Oberflächen sind getrennte Side-Views.
- UI-Eingaben werden aus `LegalActions` abgeleitet.
- `StateVersion`, Reconnect, Undo und Event-/Replay-Hinweise werden sichtbar berücksichtigt.
- Verdeckte gegnerische Kartendaten dürfen nicht sichtbar sein.
- Keine offiziellen Artworks, Logos, Card Frames, Card Backs oder externen Kartendatenbank-Stile.
