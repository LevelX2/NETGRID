# UI-Designsets

Stand: 2026-10-11

Dieser Bereich enthält die weiterhin benötigte NETGRID-Markenrichtung unter
`branding/`. Die früheren UI-Mockups und ihre Realismusprüfung wurden auf
Nutzerwunsch entfernt. Die aktuelle Oberfläche und ihr
[Strukturguide](../architecture/ui/ui-structure-guide.md) sind der Einstieg für
UI-Arbeit. Historische Entwürfe bleiben über Git nachvollziehbar.

## Gemeinsame Anforderungen

- Runner- und Corp-Oberflächen sind getrennte Side-Views.
- UI-Eingaben werden aus `LegalActions` abgeleitet.
- `StateVersion`, Reconnect, Undo und Event-/Replay-Hinweise werden sichtbar berücksichtigt.
- Verdeckte gegnerische Kartendaten dürfen nicht sichtbar sein.
- Keine offiziellen Artworks, Logos, Card Frames, Card Backs oder externen Kartendatenbank-Stile.
