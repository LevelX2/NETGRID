# Archiv

`docs/archive/` enthält historische, nicht mehr führende Artefakte, die bewusst im Arbeitsbaum bleiben sollen.

## Enthaltene Bereiche

- `mvp-0-1-0-2-document-package/`: historisches ergänzendes Dokumentenpaket für MVP 0.1 und MVP 0.2.
- `mvp-0-1-0-2-detailed-test-concept.md`: historisches detailliertes Testkonzept für MVP 0.1 und MVP 0.2.
- `originalset-spotcheck-jobs/2026-05/`: erledigte Originalset-Spotcheck-Jobfiles. Führend für die Evidence sind `docs/reviews/originalset-spotchecks/README.md`, `docs/reviews/originalset-spotchecks/register.md` und `data/reports/originalset-card-spotcheck-register.json`.

## Regel

Archivierte Dateien sind nicht automatisch Löschkandidaten. Entfernung aus Git braucht einen eigenen Rollup-, Linkprüfungs- und Retention-Schnitt.
