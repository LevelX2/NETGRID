# Icebreaker Run Semantics – verbleibende Architekturpunkte

Die Quote vereinheitlicht die deterministische Encounter-Berechnung. Noch
nicht innerhalb derselben Pfadsimulation modelliert sind probabilistische
Verzweigungen und zustandsbehaftete Folgewirkungen (Blink, Bartmoss, AI Boon,
Forward’s Legacy, Snowball, Dupré und Bulldozer). Diese Punkte bleiben bewusst
als einzelne Engine-Quote-Erweiterungen offen; es wird keine parallele
AI-Kalkulation eingeführt.
