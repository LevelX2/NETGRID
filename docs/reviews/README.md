# Reviews

Stand: 2026-08-12

`docs/reviews/` ist kein historisches Reviewarchiv. Dauerhaft bleiben hier nur Review- oder Gate-Artefakte, die heute noch unmittelbar von aktiven Tests, Scripts, Status-/Architekturentscheidungen oder Removal Conditions benötigt werden.

Abgeschlossene Implementierungsreviews, Final Reviews, Audits, Migrationsreports und generierte Evidence werden nach Referenzprüfung gelöscht, sobald ihr fachlicher Inhalt in aktuellen Verträgen, Runbooks, Code oder Tests steckt. Git-Historie übernimmt die historische Nachvollziehbarkeit.

Der verbleibende KI-Reviewbestand wird separat nach denselben Kriterien bereinigt.
